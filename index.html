Wybrane Projekty

  • SportsCar DB ↗ GitHub ↗

    VIN-centryczna platforma do monitorowania rynku aut sportowych i precyzyjnej analizy wycen w czasie. Relacyjna struktura danych opiera się na głównej tabeli unikalnych numerów VIN połączonej relacją one-to-many z tabelą obserwacji, co pozwala śledzić cykl życia i wahania cen konkretnego egzemplarza na przestrzeni czasu. Pipeline dekoduje dane bezpośrednio ze strumieni dehydratacji Otomoto (analiza obiektów JSON z __NEXT_DATA__ oraz zapytań GraphQL), a nieustrukturyzowane parametry normalizowane są przy użyciu LLM.

    Python VIN-Centric Schema (1:N Relations) Otomoto __NEXT_DATA__ Decoding GraphQL / Hydration Parsing LLM Attribute Extraction Time-Series Price Tracking
  • Yamaha Listings ↗ GitHub ↗

    Automatyczny monitoring ogłoszeń motocykli Yamaha na OLX działający w architekturze serverless. System cyklicznie odpytuje bezpośrednie wewnętrzne endpointy REST OLX w poszukiwaniu egzemplarzy spełniających określone wymagania co do modelu i silnika, pobiera szczegółowe metadane oferty, a następnie przesyła zdjęcia do multimodalnego modelu Gemini 2.5 Flash Vision. Model analizuje klatki pod kątem obecności charakterystycznego dla Yamahy fabrycznego lakieru Iconic Blue na plastikach, felgach i elementach nadwozia, automatycznie odrzucając niespełniające kryteriów ogłoszenia.

    Cloudflare Workers Gemini 2.5 Flash Vision OLX Internal REST API Serverless Cron Triggers KV Storage
  • Asystent Menago (Menago AI CRM) System Komercyjny

    Dedykowany, AI-native asystent operacyjny i system CRM stworzony dla managera artystów. Wykorzystuje moduł RAG oraz wektorowe embeddingi historycznych danych — faktur, budżetów projektowych, umów i planów — które służą asystentowi jako głęboki kontekst operacyjny do analiz i odpowiadania na pytania. Platforma automatyzuje obieg dokumentów oraz fakturowanie (OCR faktur przez Gemini 2.5 Flash Vision, czat i obsługa komend przez polski model Bielik), stosując kluczowy bezpiecznik architektoniczny Human-in-the-Loop: wszystkie propozycje zmian w danych, budżetach czy dokumentach trafiają do dedykowanej kolejki akceptacji, gdzie manager osobiście zatwierdza działania agenta przed ich realizacją.

    RAG & Vector Embeddings Human-in-the-Loop Architecture Bielik LLM (Chat & NLP) Gemini 2.5 Flash (Vision OCR) Gmail & Google Workspace API TypeScript
  • Sawmills Poland ↗ GitHub ↗

    Pipeline ETL do zautomatyzowanego pobierania, parsowania i czyszczenia danych o polskich przedsiębiorstwach drzewnych z publicznych rejestrów CEIDG i KRS. System normalizuje dane podmiotów gospodarczych, przeprowadza geokodowanie adresowe i udostępnia interaktywny dashboard analityczny z wizualizacją przestrzenną.

    Python CEIDG & KRS API Automated ETL Pipeline Geocoding & Spatial Data
  • Machine Maintenance App ↗ GitHub ↗

    Cyfrowy portal obsługi serwisowej i zamawiania części zamiennych dla maszyn przemysłowych GROSS. Wykorzystuje natywne Web API do skanowania kodów QR bezpośrednio z kamer urządzeń, interaktywny katalog z hierarchicznym drzewem podzespołów maszyn oraz dedykowany panel administracyjny do zarządzania bazą części.

    TypeScript Web QR Scanner API Hierarchical Parts Tree
